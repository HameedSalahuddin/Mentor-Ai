Product Requirements Document (PRD)
Project Codename: MentorAI

Version: 1.0

1. Vision

Create an AI-powered programming tutor that feels like a real mentor rather than a chatbot.

Unlike ChatGPT, where students need to know what questions to ask, MentorAI guides them through a structured learning journey tailored to their goals, available time, and current skill level.

The platform removes the need for prompt engineering and instead delivers a personalized curriculum, interactive coding exercises, quizzes, and AI mentorship.

2. Problem Statement

Current AI chatbots have three major problems for beginners:

Problem 1

Students don't know what to ask.

A beginner doesn't know:

What to learn first
What to learn next
Which concepts are important
Problem 2

Good learning depends on good prompts.

Example:

Instead of typing

"Teach me Python from beginner to intermediate in 60 days using active recall, quizzes, coding exercises..."

Most beginners type

"Teach me python"

The result is inconsistent.

Problem 3

Chatbots don't remember your learning journey.

They don't know

what you've mastered
what you struggle with
what you've already learned
3. Solution

MentorAI becomes a personal programming mentor.

Instead of waiting for prompts, it generates a complete personalized roadmap and guides students through it one lesson at a time.

The student simply chooses:

Programming language
Current level
Goal
Available time

The system generates everything else.

12. Success Metrics (MVP)

User receives a personalized roadmap within 30 seconds.
70%+ of users complete their first lesson.
50%+ of users return within 7 days.
Average daily study time exceeds 20 minutes.
Average quiz score improves over time for active users.
13. MVP Scope (Version 1)

Focus on doing one thing exceptionally well.

Included:

Python as the only supported language.
Personalized onboarding and roadmap generation.
AI tutor with RAG over high-quality Python resources.
Lesson pages with explanations, examples, quizzes, and coding exercises.
Built-in code editor with AI feedback.
Progress tracking and adaptive review of weak concepts.

Deferred to later versions:

Additional programming languages.
Voice conversations.
Mobile app.
Multiplayer study rooms.
Pair programming.
Gamification beyond basic streaks.
14. Long-Term Vision

MentorAI becomes the Duolingo + GitHub Copilot + Khan Academy for programming: an AI-first learning platform where students don't just ask questions—they follow a personalized, adaptive journey that helps them become confident software engineers through guided practice, real projects, and continuous feedback.
